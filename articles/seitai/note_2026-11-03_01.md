## なぜ「眼精疲労」が頑固な肩こり・頭痛を引き起こすのか（体の仕組み）

目の疲れと、首や肩のコリ、そして頭痛。一見すると別の部位の不調に見えますが、解剖学・生理学の視点で見ると**解剖学的にも神経的にも密接につながっています**。

そのメカニズムを3つのポイントで解説します。

```
【眼精疲労と頭痛・肩こりの悪循環】
スマホ・PCによる目の酷使・ピント調節（毛様体筋の疲労）
　↓
視線を固定するため「後頭下筋群」が過剰に緊張
　↓
後頭神経・大後頭神経が圧縮され「目の奥の痛み・頭痛」が発生
　↓
僧帽筋・頭板状筋へコリが拡大し「慢性的な肩こり」へ
　↓
自律神経（交感神経）の優位が続き、血行不良が加速（悪循環）
```

### 1. 目の動きを支える「後頭下筋群（こうとうかきんぐん）」の過緊張

私たちが画面を凝視するとき、目線や頭の位置がぶれないように後頭部の最も深いところにある**「後頭下筋群（大後頭直筋・小後頭直筋・上頭斜筋・下頭斜筋）」**という小さな筋肉群が過剰に働きます。

実は、**目球の動きと後頭下筋群は神経的に運動反射で連動**しています。
目が左右上下に動いたり、じっと一点を見つめたりする際、この後頭下筋群が後頭骨と首の骨（環椎・軸椎）を固定するために微細に緊張し続けているのです。

画面を何時間も見続けると、この後頭下筋群が硬く縮こまり、血行不良に陥ります。これが「首の付け根の頑固なコリ」の正体です。

### 2. 後頭神経の圧迫と「目の奥の頭痛」

後頭下筋群のすぐ近くには、後頭部から頭頂部、そして目の奥へと向かう神経（大後頭神経・小後頭神経）が走っています。
筋肉が硬く縮こまると、これらの神経や周囲の血管が圧迫されます。

神経が圧迫されると、痛みは「後頭部」だけでなく、神経の走行に沿って「頭の側面」「目の奥」へと放散します。
「肩こりや首こりがひどくなると、決まって目の奥がズキズキ奥から押されるように痛む」というのは、この神経の締め付けが大きな要因です。

### 3. 毛様体筋の疲労と自律神経の乱れ

目の中には、レンズ（水晶体）の厚みを調整してピントを合わせる**「毛様体筋（もうようたいきん）」**という小さな筋肉があります。
近くの画面を見続けるとき、毛様体筋は常にキュッと縮んだ緊張状態を保っています。

毛様体筋は自律神経（副交感神経）によって支配されていますが、長時間この筋肉に負荷がかかり続けると、自律神経のバランスが崩れ、全身の**交感神経が過剰に優位**になります。

交感神経が優位になると、全身の血管が収縮し、筋肉への酸素供給が滞ります。
その結果、表層にある大きな筋肉である**「僧帽筋（そうぼうきん）」**や**「頭板状筋（とうばんじょうきん）」**まで血流が低下して酸欠状態となり、疲労物質（乳酸など）や痛み物質（ブラジキニン）が蓄積して「頑固な肩こり」が完成してしまうのです。

つまり、目の疲れを放っておくことは、**頭の奥の筋肉を緊張させ続け、自律神経を介して肩全体を自ら硬く締め付けている**状態と言えます。

## 自宅や職場でできる！眼精疲労と肩こり・頭痛を和らげる3つのセルフケア

眼精疲労からくる首・肩のコリや頭痛を予防・改善するには、後頭下筋群の滑走性を高め、目のピント調節筋を休ませ、血流を促すことが極めて効果的です。

### セルフケア1：後頭下筋群（首の付け根）のピンポイント緩め

目の奥に響く重さを感じたときに真っ先に行ってほしい、首の奥の深層筋をピンポイントでほぐすアプローチです。

```
【やり方】
1. 両手の親指を、後頭部の骨の出っ張りから少し下に下がった「首の付け根の凹み」にあてます。
2. 残りの4本の指で頭を抱えるように固定します。
3. 親指で痛気持ちいいと感じる強さで斜め上（目の奥の方向）に向かってじわーっと圧をかけます。
4. 圧をかけた状態のまま、顔をゆっくり「上・下」に小さく5回動かします（うなずくような動作）。
5. 続いて、顔をゆっくり「左右」に小さく5回揺らします。
6. 指の位置を左右に1cmほどずらし、計3箇所ほど同様に行います。
```
**【ポイント】**
力を入れすぎて強く押しすぎないことが大切です。「じわ〜っと奥まで効いている」と感じる程度の心地よい圧で行いましょう。深呼吸を繰り返しながら行うと、より効果的です。

### セルフケア2：眼球動眼神経リリース（目の動きと首の運動分離）

目線と首の筋肉の固定をリセットし、緊張しきった毛様体筋と後頭下筋群の連動を休ませるストレッチです。

```
【やり方】
1. 背筋を伸ばして座り、まっすぐ前を見ます。
2. 顔の位置は正面に向けたまま動かさないように固定します。
3. 目線だけを最大限「右」に向け、3秒間キープします。
4. 次に目線だけを「左」に向け、3秒間キープします。
5. 同様に「上」「下」も目線だけを動かして各3秒間キープします。
6. 最後に、顔の前で自分の人差し指を立て、指先を円を描くように動かし、顔を動かさずに目だけで指先を追います（時計回りに3回、反時計回りに3回）。
```
**【ポイント】**
パソコン作業中に画面から目を離さずにいると、目球を動かす外眼筋が固まってしまいます。顔を動かさずに「眼球だけを大きく動かす」ことで、目の筋肉の血行が劇的に改善します。

### セルフケア3：ホットタオルによる後頭部・眼頭の温熱アプローチ

物理的に温めることで交感神経の過剰な緊張を解き、微細な血管を拡張させて酸素を行き渡らせるケアです。

```
【やり方】
1. 水で濡らして絞ったフェイスタオルをラップで包み、電子レンジ（600W）で40秒〜1分ほど温めてホットタオルを作ります（火傷にご注意ください）。
2. 仰向けに寝るか、椅子に深めに腰掛けます。
3. ホットタオルを「まぶたの上」から「後頭部の首の付け根」にかけて覆うように当てます。
4. 目を閉じた状態で、鼻から吸って口から吐く深呼吸を3分間繰り返します。
```
**【ポイント】**
目の上だけでなく、「後頭部の首の付け根」まで同時に温めるのが最大のコツです。後頭部を温めることで、自律神経のスイッチが副交感神経に切り替わり、全身の緊張がふっと抜けていきます。お風呂上がりや就寝前に行うと、睡眠の質を高める効果も期待できます。

**A. 強い刺激によって筋肉の繊維が微小損傷を起こし、防御反応でさらに硬くなってしまうためです。**

特に首の深層にある「後頭下筋群」や「トリガーポイント」は繊細な筋肉です。強く押しすぎると体は危険を感じて逆に筋肉を強張らせ、炎症を起こして頭痛が悪化することがあります。

### Q2. パソコン仕事中にブルーライトカット眼鏡をかけていますが、それでも眼精疲労や肩こりが良くなりません。

**A. ブルーライト対策だけでなく、「ピント調節の固定」と「姿勢の崩れ」が原因になっている可能性が高いです。**

ブルーライトは目の光刺激を和らげますが、同じ距離（画面）を長時間見続けることによる「毛様体筋の緊張」や、画面に集中するあまり顎が前に出る「ストレートネック姿勢」は防げません。
眼鏡の使用に加えて、1時間に1回は遠くを見る時間を作ったり、上記のセルフケアを取り入れたりして、物理的な筋肉の緊張をリセットすることが不可欠です。
