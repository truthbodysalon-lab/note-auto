# 単発7000円を捨て「3ヶ月15万円」に切り替えたら、新規激減でも月商200万を超えた話

「今月も新規は15人来た。でも、なぜか手元に利益が残らない…」

夜の10時、誰もいない施術室で予約表を閉じながら、そんな溜息をついたことはありませんか？

チラシを撒き、インスタグラムを更新し、割引オファーを出して新規顧客を集める。ベッドは朝から夕方まで埋まり、身体はクタクタ。それなのに、月末に口座残高を確認すると、家賃や経費、広告費を払った後は目減りした数字がポツンと残っているだけ。

「もっと新規を増やさなきゃ」
「もっとリピート率を上げなきゃ」

そう思って、さらに集客に奔走する。しかし、どれだけ頑張っても月商100万円前後を行ったり来たりして、天井にぶつかったまま抜け出せない。

実は、かつての私もまったく同じ暗闇の中にいました。

---

## 「技術を磨けば売上は上がる」という思い込みが、私を追い詰めた

整体院を経営しながら発信を続けてきた立場から、最初にお伝えしたいことがあります。

月商100万円前後で売上が停滞している最大の理由は、あなたの技術不足でも、接客の悪さでもありません。

**「単発の都度払い（1回7,000円）」という商品設計そのものが、あなたの経営を苦しめている原因**なのです。

開業当初の私は、「いい施術を提供していれば、お客様は通い続けてくれるはずだ」と信じて疑いませんでした。1回7,000円のメニューを用意し、心を込めて施術をする。来院時に「次回は来週あたりにどうぞ」と声をかける。

しかし、現実は甘くありませんでした。

* 3回ほど来院した後に、パタリと連絡が途絶える
* 「痛みが引いたから」という理由でキャンセルされる
* 天候や客足の変動で、毎月の売上が乱高下する

「来月の売上はどうなるだろう…」という不安が常に頭を離れず、精神的に追い詰められていきました。

売上を伸ばそうと施術枠を詰め込んだ結果、体力は限界に達し、一人ひとりのお客様に対する集中力も削られていく悪循環。技術セミナーに数十万円を投資して新しい手法を学んでも、経営の苦しさは1ミリも変わりませんでした。

転機が訪れたのは、ある経営者の集まりで掛けられた一言でした。

「先生、毎回『次どうしますか？』ってお客さんに決済の選択をさせてる時点で、それ『病院』じゃなくて『アミューズメント施設』と同じだよ。患者さんの痛みを本気で治したいなら、なぜ最初から『治るまでの期間と環境』を商品として売らないの？」

ハッとしました。

私は「お客様に嫌われたくない」「高額だと断られるのが怖い」という自分の都合で、1回ごとの単発払いに逃げていただけだったのです。お客様にとっても、都度払いは「毎回通うかどうか悩むストレス」を与えていただけでした。

そこから私は、都度払いを徹底的に見直し、**「3ヶ月で根本改善を目指す15万円の継続コース」**を中心としたオファー設計へと舵を切りました。

結果どうなったか。

新規の来院数は半減したにもかかわらず、売上は一気に跳ね上がり、わずか2ヶ月で月商200万円の壁を突破したのです。

この記事では、月商100万で伸び悩む先生が、恐怖を捨てて「高単価な継続コース」を構築し、お客様から感謝されながら安定した経営基盤を作るための具体的なステップをすべて公開します。

## 第1章：「都度払い」が整体院経営を壊す3つの構造的欠陥

なぜ、1回7,000円〜8,000円の単発施術を続けていると、月商100万円で頭打ちになってしまうのでしょうか。

理由はシンプルで、ビジネスモデル自体に3つの致命的な欠陥（構造的ブレーキ）が組み込まれているからです。

### 1. 「毎回、買うかどうか」の決断をお客さんに迫っている
都度払いの場合、お客様は会計のたびに「次回も7,000円を払って来る価値があるか？」を心の中で無意識に天秤にかけています。
少しでも雨が降ったり、仕事が忙しくなったり、痛みが和らいだりすると、「今日はいいかな」と離脱する理由を探してしまうのです。

### 2. 施術の目的が「痛みの解消」になり、リピートの理由が消える
単発で売っていると、お客様のゴールが「今日の痛みを取ること」になります。しかし、慢性の腰痛や肩こりは、1回の施術で一時的に楽になっても、生活習慣が変わらなければ戻ります。
1〜2回で痛みが引いた瞬間、お客様は「治った」と勘違いして来なくなり、数ヶ月後に再発して別の院へ行く。これはお客様にとっても不利益です。

### 3. LTV（顧客生涯価値）が低く、新規獲得コストに耐えられない
都度払いの平均通院回数が4回だとすると、お客様1人あたりの生涯売上（LTV）は「7,000円 × 4回 ＝ 28,000円」です。
昨今、Web集客やMEO、チラシなどで新規1人を獲得するコスト（CPA）は1万円〜1万5,000円ほどかかります。28,000円のLTVからCPAと経費を引けば、手元に残る利益はわずか。これではどれだけ集客しても疲弊するだけです。

高単価な継続コース（例：15万円）を導入することは、単に「儲けるため」ではありません。
**「お客様を確実にゴール（健康な身体）まで導く約束」を交わし、経営基盤を盤石にするための必須戦略**なのです。

## 第2章：売れる「3ヶ月15万円継続コース」の設計手順

「でも、急に15万円のコースなんて作っても、誰も買ってくれないのでは…」
そう不安に思うかもしれません。しかし、正しいコンセプトとステップで設計すれば、お客様の方から「それを受けたいです」と言っていただけるようになります。

ここでは、実際にある整体院で成果を出したコース設計の4ステップを解説します。

### ステップ1：ターゲットの「悩み」ではなく「未来」を言語化する
コースの価値は、施術の「分数」や「手技の珍しさ」ではありません。
**「このコースを終えた時、どんな生活が手に入っているか」という未来（ベネフィット）**です。

* ✖ 悪例：「60分×10回の骨盤矯正・姿勢改善コース」
* ◯ 改善例：「朝起きた瞬間の腰の重だるさから解放され、週末に子どもと全力で公園で走れるようになる『3ヶ月腰痛根本改善プログラム』」

### ステップ2：期間と回数を「ゴールから逆算」して提示する
ダラダラ通わせるのではなく、「なぜ3ヶ月なのか」「なぜ10回なのか」の根拠を施術理論に基づいて提示します。

* **1ヶ月目（初期フェーズ・4回）：** 歪みのリセットと炎症の抑制（週1回）
* **2ヶ月目（定着フェーズ・4回）：** 正しい姿勢の記憶と筋膜の定着（2週に1回）
* **3ヶ月目（メンテナンスフェーズ・2回）：** 再発しない身体作りとセルフケア習得（月1回）

このように、「期間ごとのテーマ」を明示することで、お客様は「だからこの回数が必要なんだ」と納得します。

### ステップ3：施術以外の「付加価値（特典）」をパッケージ化する
コースの価値を高めるために、院内での施術以外のサポートを盛り込みます。

* あなた専用の「個別セルフケア動画」の配信
* 期間中、LINEでの姿勢・生活習慣のご相談が無制限
* 姿勢分析シート・改善ロードマップの進呈

これにより、「施術代」ではなく「健康になるための包括的サポートプログラム」として認識され、価格に対する抵抗感が一気に下がります。

### ステップ4：価格と決済方法の設計
「15万円」という金額を一括で支払える人ばかりではありません。
必ず「分割決済（クレジットカードや社内分割）」の選択肢を用意してください。

* 一括払い：150,000円（特典あり）
* 3分割払い：月々50,000円 × 3回

「月々5万円（1日あたり約1,600円）で、長年悩んだ腰痛が根本から消える」と提示できれば、都度払いで何年も通い続けるより遥かに賢い投資だと理解してもらえます。

## 第3章：押し売りゼロで成約率8割を超えるカウンセリング・トークの全貌

どれだけ素晴らしいコースを作っても、カウンセリングで「売り込まれた」と感じさせてしまっては成約しません。
高単価コースを成約させるコツは、**「売る」のではなく、「お客様自身に自分の現状と未来の必要性を気づいてもらう」こと**です。

カウンセリングの流れは、以下の「5ステップ」で進めます。

```
【成約率8割のカウンセリング・フロー】

1. ヒアリング（過去の体験と理想のゴール）
   ↓
2. 検査・分析（現在地の見える化）
   ↓
3. ギャップの提示（なぜ今まで治らなかったのか）
   ↓
4. ギャップを埋めるプランの提案（コースの提示）
   ↓
5. 意志確認（「一緒に頑張りますか？」）
```

### 1. ヒアリング：単なる症状ではなく「制限されていること」を聞く
「どこが痛いですか？」だけで終わらせてはいけません。

* **質問：**「その腰の痛みのせいで、本当はしたいのに諦めていることや、困っていることは何ですか？」
* **目的：** 痛みの先にある「感情の悩み（孫を抱っこしたい、旅行に行きたいなど）」を引き出す。

### 2. 検査・分析：プロとしての見立てを「視覚化」する
姿勢写真の撮影や可動域検査を行い、お客様自身に「自分の身体がいかに崩れているか」を客観的に確認してもらいます。

### 3. ギャップの提示：なぜ都度払いでは治らないかを説明する
ここが最も重要なポイントです。

> **【カウンセリング・トーク例】**
> 「〇〇さん、今日施術をすれば、お痛みを半分以下に減らすことはできます。ですが、〇〇さんの骨盤の歪みと筋力の状態を見ると、3日も経てば元の悪い状態に戻ってしまいます。
> 今までいろんなマッサージや整体に行ってもすぐ戻っていたのは、この『戻り』が起きる前に適切なケアを重ねていなかったからです。本気で元の健康な状態に戻すには、細胞の生まれ変わり周期に合わせた『3ヶ月間』の計画的なアプローチが不可欠なのですが、〇〇さんは『一時的な気休め』と『根本的な改善』、どちらを望まれていますか？」

この質問に対して、9割以上のお客様が「根本的に治したいです」と答えます。

### 4. ギャップを埋めるプランの提案
お客様が「根本改善」を選択したタイミングで、初めてコースの説明に入ります。

> **【提案トーク例】**
> 「承知いたしました。では、〇〇さんが『痛みなく旅行に行ける身体』を取り戻すために最適な、3ヶ月間の改善プログラムをご提案させていただきますね。」

説得するのではなく、お客様が求めた「根本改善」という目的に対する唯一の解決策としてコースを提示するのです。

## 第4章：既存客を傷つけずに「コース型」へ移行する完全ロードマップ

新しく来院する新規顧客に対してはカウンセリングでコースを提案できますが、問題は「すでに1回7,000円で通っている既存のお客様」です。

「急に高額コースを提案したら、全員離れてしまうのではないか…」

そう心配される経営者の方は非常に多いです。しかし、丁寧な「段階的移行（ステップ移行）」を行えば、既存のお客様からも喜ばれながらコースへ移行していただけます。

既存客へアプローチする具体的手順は以下の通りです。

```
【既存客のコース移行 30日ロードマップ】

【1〜10日目】「お知らせ」と「意識変革」の告知
・院内掲示やLINEで「〇月より、より確実に成果を出すための根本改善専門院へとリニューアルします」と告知。
・なぜ方針を変えるのか、院長の想い（「患者さんの痛みを本気で解消したいから」）を伝える。

【11〜20日目】個別カウンセリングの実施
・既存客の来院時に5分間の特別時間をとり、現在の回復状況と「今後のゴール設定」を再確認する。
・「〇〇さんの状態をさらに良くするために、専用の計画を立てました」とアプローチ。

【21〜30日目】移行特別オファーの提示
・「これまで通ってくださった感謝を込めて、既存の患者様限定で特別モニター枠をご用意しました」と提案。
```

重要なのは、**「値上げやコース化は、患者様のお悩みをより確実に解決するための進化である」という情熱と理由をしっかり伝えること**です。単なる値上げではなく、価値の再定義であることを理解してもらえれば、信頼関係のある既存客ほど「先生がそこまで言うなら、お任せします」と応援してくれます。

## 第5章：月商200万を維持する「高単価×省時間」の店舗経営モデル

継続コース（高単価商品）が定着すると、院の経営数字と日々の働き方は劇的に変化します。

都度払い（1回7,000円）で月商100万円を目指す場合と、3ヶ月15万円コースを導入して月商200万円を達成する場合の数字を比較してみましょう。

| 項目 | 都度払いモデル（従来） | 高単価コースモデル（導入後） |
| :--- | :--- | :--- |
| **目標月商** | 100万円 | **200万円** |
| **単価（客単価/LTV）** | 7,000円 / LTV約2.8万円 | **LTV 15万円（コース）** |
| **必要な新規獲得数** | 月20人〜30人（集客地獄） | **月8人〜10人**（集客負担小） |
| **必要な成約数** | - | **月8件（15万円×8＝120万円）** |
| **既存メンテナンス** | 延べ140回以上の施術 | **約50回〜60回の施術＋残売上** |
| **施術労働時間** | 月150時間以上（限界） | **月70時間〜80時間**（半分に減！） |

ご覧のように、売上が2倍になっているにもかかわらず、**施術にかける労働時間は半分近くに減少**します。

労働時間が減ることで、以下のようなメリットが生まれます。

1. **一人ひとりのお客様に全力で向き合える**（満足度と成果がアップ）
2. **空いた時間でマーケティングや発信、技術研鑽ができる**
3. **体調やメンタルが安定し、経営者としての判断力が高まる**

月商100万円の壁を越えられない整体師の多くは、「集客の量」を増やそうとして自滅します。
必要なのは量ではなく、**「構造の変更」**です。「少ない客数で、高い価値を提供し、大きな利益を得る」モデルへとシフトすることが、個人サロンや小規模整体院が生き残る唯一の道なのです。
