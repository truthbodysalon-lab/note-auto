# 口コミ数より「週3回の更新」だった——90日でマップ経由の相談が増えた理由

## 「口コミが少ないから、Googleマップでは勝てない」と諦めていませんか？

「近くの院は口コミが100件以上。こちらはまだ20件。この差では上に出られない」

「定期的に投稿しているけれど、本当に意味があるのかわからない」

「Googleマップを見た人が、その後どこを見て判断しているのかつかめない」

月商100万円前後で停滞していた頃、私も同じことを考えていました。

Googleビジネスプロフィールには登録済み。営業時間も入力した。写真も何枚か載せた。それでも、マップ経由の問い合わせは月に1〜2件ほどでした。

競合を検索すると、口コミ数は自分の何倍もある。

その数字を見ては、

「今から追いつくのは無理だ」

と感じ、更新を後回しにしていました。

ところが、ある日お客様からこんなことを言われたんです。

「口コミが一番多いところも見ました。でも、最近の写真がなくて、今もちゃんと営業しているのかわからなかったんです」

その一言で、私は大きな勘違いに気づきました。

Googleマップを見る人が確認しているのは、口コミの件数だけではありません。

「ここは自分に合いそうか」

「今もきちんと営業しているか」

「どんな人が、どんな考えで対応しているか」

こうした複数の材料を見ながら、相談するかどうかを決めています。

そこで私は、口コミ数だけを追いかけるのをやめました。

代わりに取り組んだのが、週3回の情報更新と、相談までの導線整理です。

最初の30日でプロフィールの閲覧後に行動する人が少しずつ増え、90日後にはマップを見た人からの相談が安定して入るようになりました。

大きな広告費を使ったわけではありません。

口コミを短期間で大量に集めたわけでもありません。

変えたのは、Googleマップを「店舗情報を置く場所」から「来店前の不安を解消する接客ページ」へ捉え直したことでした。

この記事では、私が実践した週3回の更新設計を、5つの章に分けて具体的にお伝えします。

## 院長の体験・気づき——止まっていたのは順位ではなく、お客様の判断だった

当時の私は、毎週のように検索順位を確認していました。

「地域名＋整体」

「地域名＋肩こり」

「地域名＋腰痛」

順位が上がれば喜び、下がれば落ち込む。

まるで順位そのものが売上を作っているように考えていたのです。

しかし、数字を整理してみると、別の問題が見えてきました。

プロフィールは見られているのに、その後の行動につながっていなかったのです。

つまり、問題は「発見されていないこと」だけではありませんでした。

発見された後に、

「ここへ相談して大丈夫だろうか」

という不安を解消できていなかったのです。

当時のプロフィールには、施術ベッドの写真、入口の写真、営業時間、短い説明文しかありませんでした。

提供者の考え方も、初回の流れも、どのような悩みを相談できるのかも伝わりません。

これでは、初めて見る人が判断できなくて当然です。

私はGoogleマップを、単なる検索対策だと思っていました。

でも実際には、検索結果に表示された後の「比較」と「信頼形成」まで含めて設計する必要があります。

ここで、私は運用方針を変えました。

順位を毎日確認するのではなく、お客様が抱える疑問を毎週3つ解消する。

この方針に切り替えてから、投稿内容に迷う時間も減りました。

## 第1章：Googleマップ集客を「3段階」に分ける

Googleマップから相談につなげるには、次の3段階を通過してもらう必要があります。

1. 発見される
2. 比較される
3. 信頼される

多くの院が力を入れているのは、1つ目の「発見される」だけです。

カテゴリを設定し、説明文にサービス内容を記載し、口コミを増やす。もちろん、これらは大切です。

しかし、表示されたとしても、その先で選ばれなければ相談にはつながりません。

たとえば、検索結果に3つの院が表示されたとします。

A院は口コミ120件。ただし、写真も投稿も半年前で止まっている。

B院は口コミ45件。毎週、院内の様子や考え方を発信している。

C院は口コミ18件。基本情報が少なく、どんな院なのかわからない。

件数だけならA院が有利です。

ところが、初めて整体を受ける人や、過去に合わない施術を経験した人は、件数以外の情報も慎重に確認します。

そのとき、B院の投稿に、

「初回は施術に入る前に、現在困っている動作や生活場面を確認します」

と書かれていたらどうでしょうか。

不安を具体的に解消できるため、B院が選ばれる可能性は十分にあります。

ここで重要なのは、口コミ数を軽視することではありません。

口コミ数だけでは埋められない判断材料を、写真、投稿、説明文、返信で補うことです。

まずは自分のプロフィールを、次の3つの視点で確認してください。

- 検索した人に見つけてもらえる情報があるか
- 他院と比較するときの判断材料があるか
- 初めて相談する人の不安を解消できているか

この3つのどこで止まっているかがわかれば、打ち手はかなり明確になります。

## 第2章：週3回の投稿は「症状・人柄・利用イメージ」に分ける

「何を投稿すればいいかわからない」

これは、Googleマップ運用で最も多い悩みの一つです。

私は投稿を3種類に固定しました。

### 月曜日：悩みを理解する投稿

月曜日は、お客様が検索しそうな悩みを取り上げます。

ただし、症状名を並べるだけでは不十分です。

日常の具体的な場面まで書きます。

テンプレートは次のとおりです。

> 「〇〇をすると△△が気になる」という相談があります。  
> 同じ悩みでも、負担がかかる場面や生活習慣は人によって異なります。  
> まずは、いつ、どんな動作で困っているのかを整理することが大切です。

たとえば肩まわりの悩みなら、「肩こりに対応しています」だけで終わらせません。

「夕方になると首から肩が重くなり、仕事に集中しにくい」

「朝、振り向く動作で違和感がある」

このように、お客様の頭の中にある言葉へ近づけます。

### 水曜日：考え方や人柄を伝える投稿

水曜日は、技術の自慢ではなく、対応するときに大切にしている考え方を伝えます。

テンプレートはこちらです。

> 私が初回に大切にしているのは、〇〇です。  
> なぜなら、△△のまま進めると、お客様との認識にズレが生まれるからです。  
> そのため、最初に□□を確認するようにしています。

「丁寧に対応します」だけでは、他院との違いがわかりません。

何を丁寧に確認するのか。

なぜそれを重視しているのか。

この2点まで書くと、考え方が伝わります。

### 金曜日：利用場面を想像できる投稿

金曜日は、初めての人が流れを想像できる投稿です。

> 初めて相談するときに、「何を話せばいいかわからない」と感じる方もいます。  
> すべてを整理してから話す必要はありません。  
> 困っている動作や、今後できるようになりたいことから順番に確認していきます。

持ち物、服装、所要時間の考え方、相談時によくある質問なども題材になります。

この3種類を繰り返せば、投稿ネタを毎回ゼロから考える必要はありません。

週3回が難しければ、まずは週1回でも構いません。

大切なのは、無理な頻度で始めて1カ月で止まることではなく、同じ役割の情報を積み上げることです。

## 第3章：写真は「きれいさ」より5つの不安解消で選ぶ

私が以前載せていたのは、無人の施術スペースばかりでした。

室内は伝わりますが、「どのように対応されるのか」は伝わりません。

そこで、写真を次の5種類に分けました。

1. 外から見たときの雰囲気
2. 受付や案内の様子
3. 話を聞く場面
4. 状態を確認する場面
5. 衛生管理や準備の様子

写真の目的は、映えることではありません。

初めての人の頭にある「わからない」を減らすことです。

特に重要なのは、人物の気配です。

無人の部屋だけが並んでいると、提供者の表情や距離感を想像できません。

一方、会話している場面や説明している場面があると、利用時のイメージが具体的になります。

ただし、施術結果を断定する表現や、過度なビフォーアフターには注意が必要です。

「一度で改善する」

「必ず変化する」

といった表現ではなく、何を確認し、どのように進めるかを伝えます。

写真を追加するときは、次の問いを使ってください。

> この写真は、お客様のどんな不安を減らすのか？

答えられない写真は、にぎやかしになっている可能性があります。

反対に、少し地味でも不安を減らせる写真には価値があります。

## 第4章：口コミは件数ではなく「選ぶ理由」を増やす

口コミをお願いするとき、

「よかったら口コミをお願いします」

だけで終わっていないでしょうか。

この頼み方では、お客様も何を書けばいいかわかりません。

結果として、

「よかったです」

「丁寧でした」

という短い感想になりやすくなります。

もちろん、その感想もありがたいものです。

ただ、これから相談を考える人にとっては、もう少し具体的な情報があると判断しやすくなります。

私は、お願いするときの言葉を次のように変えました。

> もしご負担でなければ、最初にどんなことで困っていたか、相談するときに不安だったこと、実際に受けてみて感じたことを書いていただけると、同じ悩みを持つ方の参考になります。

書く内容を強制するのではなく、思い出すための視点を渡します。

さらに重要なのが返信です。

返信は、投稿者だけに向けたものではありません。

今後その口コミを読む人にも見られます。

返信テンプレートは、次の4要素で作れます。

> 〇〇についてご感想をいただき、ありがとうございます。  
> 最初は△△に不安を感じていらっしゃいましたね。  
> 今回は□□を確認しながら進めました。  
> 今後も、その時々の状態や生活に合わせて一緒に整理していきます。

個人情報や詳しい状態を書きすぎないことは大前提です。

そのうえで、どのような姿勢で対応しているのかを返信から伝えます。

なお、口コミへの特典提供や、良い評価だけを求める行為は避けるべきです。

短期的に件数を増やせても、信頼を損なえば本末転倒です。

求めたいのは高評価そのものではなく、実際の体験に基づく率直な声です。

## 第5章：90日ロードマップ——見る数字を3つに絞る

MEOは、数日で結論を出す施策ではありません。

プロフィールを整え、情報を積み重ね、反応を確認する期間が必要です。

私は90日を3つに分けて進めました。

### 1〜30日目：土台を整える

最初の30日は、基本情報と素材をそろえます。

- 主なカテゴリと関連情報を確認する
- 営業時間やサービス情報の誤りを直す
- 紹介文を、お客様が理解できる言葉に直す
- 不安解消につながる写真を10枚用意する
- 週3回の投稿を始める
- 未返信の口コミへ丁寧に返信する

この段階では、順位の上下に一喜一憂しません。

まず「見つけた人が判断できる状態」を作ります。

### 31〜60日目：反応のある題材を見つける

次の30日は、どの投稿や写真が反応につながっているかを確認します。

難しく考える必要はありません。

お客様との会話で、

「投稿に書いてあった〇〇を見ました」

「写真を見て、話しやすそうだと感じました」

と言われた内容を記録します。

ある整体院では、専門的な解説よりも「初回に何を確認するか」を説明した投稿のほうが、お客様から多く言及されました。

発信者が伝えたい情報と、お客様が知りたい情報は一致しないことがあります。

実際の会話を手がかりに修正してください。

### 61〜90日目：相談までのつながりを整える

最後の30日は、プロフィールを見た人が次に迷わない状態を作ります。

ここで確認する数字は、次の3つで十分です。

- プロフィールが表示された回数
- 閲覧後に行動した回数
- マップを見たと確認できた相談数

表示回数だけ増えても、相談が増えていなければ、比較や信頼形成に課題があるかもしれません。

逆に、表示回数が大きく増えていなくても、相談が増えているなら、情報の質が改善した可能性があります。

月ごとの記録テンプレートは、次のようにシンプルで構いません。

| 項目 | 今月 | 前月 | 気づき |
|---|---:|---:|---|
| プロフィール表示 |  |  |  |
| 閲覧後の行動 |  |  |  |
| マップ経由の相談 |  |  |  |
| よく見られた題材 |  |  |  |

「検索順位が何位だったか」だけを記録するより、経営に近い行動を見ることが大切です。

順位は目的ではありません。

必要としている人に見つけてもらい、不安を減らし、相談という次の行動へ進んでもらうことが目的です。

## あなたへの問い——プロフィールは「営業中」になっていますか？

Googleビジネスプロフィールに登録していることと、活用できていることは違います。

情報が古い。

写真が数カ月変わっていない。

投稿が告知ばかりになっている。

口コミに返信していない。

もし一つでも当てはまるなら、あなたの技術が不足しているのではありません。

来店前のお客様が判断するための材料が、まだ足りていないだけです。

今日、まず一つだけ直すなら、最新の投稿を確認してください。

その投稿は、売り手が伝えたいことだけを書いていないでしょうか。

お客様の不安を一つ減らせているでしょうか。

口コミ100件を一気に目指す必要はありません。

まずは週3回、難しければ週1回でもいい。

悩みを理解する投稿。

人柄や考え方を伝える投稿。

利用場面を想像できる投稿。

この3種類を積み重ねてください。

Googleマップ集客は、検索順位を競うだけのゲームではありません。

画面の向こうで迷っている一人に、「ここなら相談できそう」と感じてもらうための接客です。

その視点を持てたとき、Googleマップは放置された店舗情報ではなく、24時間働く信頼形成の入り口へ変わります。
